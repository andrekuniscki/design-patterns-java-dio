# Design Patterns com Java

Projeto desenvolvido como parte do desafio de Design Patterns do bootcamp DIO.

## Padrões implementados

- Singleton (Lazy e Eager)
- Strategy

## Como usar

Os arquivos .java representam exemplos simples dos padrões, sem dependência de bibliotecas externas.

## Estrutura de pacotes

- `singleton` — exemplos de Singleton  
- `strategy` — interface e implementações  
- `Main.java` — demonstra o uso
